## About me

I'm a student at **BMS Institute of Technology and Management** in Bengaluru. I like
problems where correctness matters: money that has to add up, pipelines that keep
running when an API rate-limits them, and systems that tell you what went wrong.

- Working on: **LedgerFlow**, a wallet and ledger API ([live](https://ledgerflow-console.vercel.app))
- Interested in: backend engineering, ML and MLOps, DevOps, VLSI
- Open to: internships and full-time roles
